# AutoResearch continuation

Keep the protocol and original studies immutable. Inspect the failed mechanisms,
state a falsifiable hypothesis, and declare a finite ordered batch. Run every
candidate on the same nine development days and first 15 seconds of labels.
Compare against the inherited strongest baseline, never against a weaker method.
Record all trials, including crashes and failed hypotheses. Stop candidate search
on its first passing gate, then freeze before any final access.

Use existing NumPy and the locked environment. Bound memory by constructing
causal features in chunks. Check this construction against the existing feature
builder and check inherited baseline scores before interpreting new results.
Do not reinterpret a development-selected success as an independent replication.

If no candidate passes, diagnose that batch and continue with another declared
batch under the same threshold and access restrictions. Never drop recordings,
extend calibration time, pool labels across development days, or tune on final
results to manufacture success.

New candidate mechanisms belong in immutable single-file methods. Bind each
trial to its selected method and the fixed core. Add methods without editing
previous method files, source loaders, scoring, or historical evidence. Freeze
all used methods at the first passing gate. The archived 38 continuation
attempts and original 32 configurations remain visible in cumulative counts.
